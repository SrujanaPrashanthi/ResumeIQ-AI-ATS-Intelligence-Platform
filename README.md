# ResumeIQ – AI ATS Intelligence Platform (Agentic AI)

## 🚀 Overview
This project is an Agentic AI system that analyzes resumes and provides intelligent insights.

## 🧠 Features
- Resume analysis using AI
- Job matching support
- Intelligent recommendations

## ⚙️ Tech Stack
- Python
- Google Cloud (Vertex AI / APIs)
- LangChain

## ▶️ How to Run
This project is designed to run on Google Cloud environment.

Steps:
1. Open Google Cloud Console
2. Set up Vertex AI / Notebook
3. Install required libraries
4. Run main.py

## 📦 Requirements
See requirements.txt

## ⚠️ Note
This project may not run locally without proper cloud setup.
